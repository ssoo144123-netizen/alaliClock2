# ساعت جلالی (Jalali Clock)

ساعت آنالوگ فارسی با تاریخ شمسی، آلارم،  اسکرین‌سیور، و ویجت خاموشی.
حداقل نسخه اندروید: **6.0 (API 23)**

## دریافت APK (بدون نیاز به کامپایل)

- هر بار که کد push شود، GitHub Actions یک APK می‌سازد. از تب **Actions** > آخرین اجرا > بخش **Artifacts** دانلود کنید.
- برای نسخه رسمی: `git tag v0.1.0 && git push origin v0.1.0` را اجرا کنید تا APK در بخش **Releases** منتشر شود.
- فایل را روی گوشی اندروید ۶ یا بالاتر نصب کنید. اگر نصب بلاک شد، «نصب از منابع ناشناس» را برای مرورگر یا فایل‌منیجر فعال کنید.

## نصب و اجرا (با Android Studio)

1. پوشه را در Android Studio باز کنید (`File > Open`).
2. Gradle را sync کنید. Android Studio فایل wrapper را می‌سازد.
3. روی دستگاه یا شبیه‌ساز API 23 اجرا کنید.
4. یا از تب **Actions** در GitHub آخرین APK دیباگ را دانلود کنید.

## تنظیمات

- برای باز کردن تنظیمات، روی ساعت نگه دارید.
- **اسکرین‌سیور:** از داخل تنظیمات برنامه، «انتخاب اسکرین‌سیور» را بزنید و «ساعت جلالی» را انتخاب کنید.
- **ویجت خاموشی:** ویجت «خاموش کردن صفحه» را به صفحه اصلی اضافه کنید. بار اول از شما خواسته می‌شود مدیر دستگاه را فعال کنید.

## دسترسی‌ها

- **READ_CALL_LOG** و **READ_SMS** برای نمایش تماس بی‌پاسخ و پیام خوانده‌نشده، در اولین اجرا پرسیده می‌شود.
- **Device Admin** فقط برای قفل کردن صفحه با ویجت لازم است.

## نکته‌ها

- فایل صوتی `res/raw/alarm.wav` از APK اصلی گرفته شده است.
- صدای tick و چایم در کد تولید می‌شوند، چون کلیپ مناسبی در APK اصلی پیدا نشد.
